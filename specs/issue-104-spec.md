# Technical Spec: [お金・家計] Uber Eatsでの自動更新のトラブルにより、解約後も料金が引き落とされ続けている。

_Source: Issue #104_

### 要件定義
- R1. ユーザーとして、Uber Eatsの自動更新状況を確認したい、なぜなら解約後も料金が引き落とされるトラブルを避けたいから。
- R2. ユーザーとして、簡単に解約手続きを行いたい、なぜなら手続きが煩雑で時間がかかることを避けたいから。
- R3. ユーザーとして、自動更新の通知を受け取りたい、なぜなら自分の支出を把握したいから。
- R4. ユーザーとして、過去の支払い履歴を確認したい、なぜなら自分の支出を管理したいから。
- R5. ユーザーとして、サポートへの問い合わせを簡単に行いたい、なぜなら問題解決を迅速に行いたいから。

### 技術スタック
- フロントエンド: React Native
- バックエンド: Node.js + Express
- DB: MongoDB
- インフラ/デプロイ: AWS (EC2, S3, RDS)

### データモデル
| エンティティ | 主要フィールド | リレーション |
|--------------|----------------|--------------|
| User         | id, name, email, subscriptionStatus, paymentHistory | 1対多 (User - Payment) |
| Payment      | id, userId, amount, date, status | 多対1 (Payment - User) |
| Subscription | id, userId, service, status, renewalDate | 1対1 (Subscription - User) |

### API エンドポイント
| メソッド | パス                      | 説明                         |
|----------|--------------------------|------------------------------|
| GET      | /api/users/{id}          | ユーザー情報を取得           |
| GET      | /api/users/{id}/payments  | ユーザーの支払い履歴を取得   |
| GET      | /api/users/{id}/subscription | ユーザーのサブスクリプション情報を取得 |
| POST     | /api/users/{id}/subscription/cancel | サブスクリプションを解約する |

### 画面一覧
| パス                     | 画面名               | 主要コンポーネント               |
|-------------------------|---------------------|----------------------------------|
| /subscriptions          | サブスクリプション管理 | サブスクリプションリスト、解約ボタン |
| /payments               | 支払い履歴           | 支払い履歴リスト                 |
| /settings               | 設定                 | 通知設定、サポートへのリンク     |
