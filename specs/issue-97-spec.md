# Technical Spec: [食事・料理] 自炊のモチベーションが低下しており、コンビニ飯に飽きているが、自分で料理を作る気力がない。特に最近のコンビニ弁当が高すぎると感じている。

_Source: Issue #97_

### 要件定義
- R1. 「忙しい社会人や学生として、簡単に自炊のレシピを提案されたい、なぜなら料理をする気力がないから。」
- R2. 「ユーザーとして、買い物リストを自動生成してもらいたい、なぜなら食材を揃えるのが面倒だから。」
- R3. 「ユーザーとして、他のユーザーのレシピを評価したりコメントしたりしたい、なぜならコミュニティの意見を参考にしたいから。」
- R4. 「ユーザーとして、レシピの調理時間や難易度を確認したい、なぜなら自分のライフスタイルに合ったレシピを選びたいから。」
- R5. 「ユーザーとして、過去に作ったレシピを保存しておきたい、なぜなら再利用したいから。」

### 技術スタック
- フロントエンド: React Native
- バックエンド: Node.js (Express)
- DB: MongoDB
- インフラ/デプロイ: AWS (EC2, S3)

### データモデル
| エンティティ | 主要フィールド | リレーション |
|--------------|----------------|--------------|
| User         | id, name, email, password | レシピ (1:N) |
| Recipe       | id, title, ingredients, instructions, cooking_time, difficulty, user_id | ユーザー (N:1), コメント (1:N) |
| Comment      | id, content, user_id, recipe_id | ユーザー (N:1), レシピ (N:1) |

### API エンドポイント
| メソッド | パス                | 説明                          |
|----------|---------------------|-------------------------------|
| GET      | /api/recipes        | レシピ一覧を取得              |
| POST     | /api/recipes        | 新しいレシピを作成            |
| GET      | /api/recipes/:id    | 特定のレシピを取得            |
| POST     | /api/recipes/:id/comments | レシピにコメントを追加      |
| GET      | /api/users/:id/recipes | ユーザーのレシピ一覧を取得  |

### 画面一覧
| パス             | 画面名         | 主要コンポーネント         |
|------------------|----------------|----------------------------|
| /                 | ホーム         | レシピリスト, 検索バー     |
| /recipe/:id      | レシピ詳細     | レシピ情報, コメントセクション |
| /create-recipe    | レシピ作成     | フォーム (タイトル, 材料, 手順) |
| /user/:id/recipes | ユーザーのレシピ | ユーザーのレシピリスト     |
