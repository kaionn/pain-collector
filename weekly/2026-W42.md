## 1. 食事・体重記録アプリの操作性と精度への不満 (9/10) 📈

- カテゴリ: 健康・体調
- 出現回数: 107 回 / 方向: rising
- 分析: 出現数が全体で最多です。毎日記録する習慣系の用途なので、ちょっとした手間の増加が強い不満になります。既に課金しているユーザーの声も多く、記録を最短化する代替アプリにはサブスク型で乗り換え需要が見込めます。

代表的なペイン:
- 食事管理アプリのアップデートで、トップ画面に食事内容が表示されなくなった。体重記録にもスクロールが必要になり、毎日の記録の手間が増えた
- MyFitnessPalとiPhoneのヘルスケアが連携できず、サブスク料金を払っているのに食事や運動のデータが統合されない
- 食事記録AIが写真から料理の量を推定できず、基礎代謝も計算に含まれないため、カロリー管理の精度が低い


## 2. 家族向け写真・動画共有の容量・長さ制限 (8/10) 📈

- 子どもの長い動画（発表会・運動会など）を祖父母と共有できない

- ローカル線の交通系ICカードの残高をスマホで確認できない

## 🌍 言語横断分析

### グローバルトレンド（日英両方で出現）

- 非エンジニアのサイト障害診断
  - This pain shows up in both languages. A browser extension or service that explains console errors in plain language and suggests fixes would reach small businesses worldwide.

### 🎯 ローカライズチャンス（英語圏のみ → 日本未参入）

- AIツール間のコンテキスト共有・個人知識の一元化
  - 英語圏: Users of several AI agents and tools (ChatGPT, Claude, Cursor and others) must re-explain the same context and preferences to each one. Their knowledge is scattered across tools.
  - Japanese users also run several AI tools side by side. A memory layer that keeps Japanese-specific context (honorific style, business conventions) and shares it across tools has room to grow.
- 多言語翻訳ファイルのタグ・プレースホルダー破損チェック
  - 英語圏: When translation files for many languages contain HTML tags and placeholders, translators break the tags or drop placeholders, which breaks the UI.
  - Japanese translation often reorders words and uses full-width characters, so placeholders break easily. A validation tool for localization projects targeting Japan has strong demand.
- Webhookペイロードの捕捉と型自動生成
  - 英語圏: When building webhook integrations, it is hard to catch and inspect the payloads that actually arrive. Developers end up writing TypeScript type definitions for them by hand.
  - There are few tools that come with ready-made samples for Japanese payment and messaging webhooks such as PAY.JP, LINE, and freee. A localized version could stand out.
- タスク・プロジェクト切替時のワークスペース復元
  - 英語圏: Each time users switch tasks or projects, they must reopen and rearrange the apps, tabs and accounts they need. This loses time and breaks their focus.
  - Japanese office workers who switch between many SaaS tools and accounts, such as Chatwork, kintone, and Slack, often face the same pain. A context-switching tool built for Japanese SaaS could be a winner.
- 開発環境の不整合・エラー原因の診断
  - 英語圏: In setups combining VS Code, WSL2, and Docker, it's unclear which environment the extension runs commands in. Diagnosing why Docker isn't found takes a lot of time.
  - Japanese-language guidance for diagnosing development environments is thin, so a CLI that automatically identifies the cause and explains it in Japanese has value.
